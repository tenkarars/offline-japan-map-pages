OFFLINE MAP

山へ行く前に地図を保存

国土地理院の地図から必要な範囲を選び、端末に保存できます。通信が不安定な場所でも、保存した地図とGPS現在地を確認できます。

ROUTE PLANNING

予定ルートと登山道を地図上で確認

予定ルートの作成、チェックポイント、百名山カードの同梱ルートを地形図に重ねて確認できます。

RAIN CLOUDS

オンラインでは雨雲の動きも確認

気象庁の雨雲の動きを地図に重ねます。雨雲表示はオンライン専用で、登山可否や安全を判定する機能ではありません。
