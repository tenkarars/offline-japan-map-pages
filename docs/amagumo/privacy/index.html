AMAGUMO プライバシーポリシー

iOSアプリにおけるデータの扱いについて説明します。

最終更新日: 2026-08-11

1. 開発者が独自に収集しないデータ

AMAGUMOは、開発者が運営する独自サーバーへ位置情報、表示地点、利用履歴などのユーザーデータを送信しません。広告、トラッキング、アカウント機能、外部解析SDKは使用しません。

2. 位置情報

位置情報は、現在地を地図上に表示し、現在地付近へ地図を移動し、起動時に現在地セルの雨量強度色を取得するために使用します。正確な緯度・経度とピクセル位置は端末内で処理し、開発者の独自サーバーへ送信・保存しません。

雨量色と地図を取得する際は、現在地または表示地点を含む広い範囲のタイル識別子を気象庁または国土地理院へ送信します。これは正確な座標ではありませんが、概略位置に相当する場合があります。位置情報の許可はiPhoneの「設定」でいつでも取り消せます。許可しない場合も、地図を手動で移動して利用できます。

3. 端末内に保存する情報

最後に表示した地図の中心位置とズームを、アプリの端末内設定へ保存します。現在地へ地図を移動した場合、保存される地図中心がその時点の現在地と一致することがあります。雨雲データのオフライン保存、アカウント、クラウド同期は行いません。

兄弟アプリとの地点受け渡しを利用した場合、緯度、経度、ズーム、作成時刻、送信元を同じApple Developer TeamのApp Group領域へ短時間だけ保存し、読み取り後または有効期限後に再利用しません。これらをWeb URLへ含めません。

端末内の地図設定は次の操作で上書きされ、アプリを削除すると消去されます。開発者は独自サーバー上に利用者データを保持しないため、開発者への削除依頼が必要となるサーバーデータはありません。

4. 地図・雨雲表示時の通信

雨雲の時刻情報、雨量色、雨域画像を取得するため気象庁へ、背景地図を表示するため国土地理院へ通信します。各配信元には、通常のインターネット通信に伴うIPアドレス、日時、リクエストしたタイル識別子やURL、OSなどの通信情報が届き、各配信元の方針に基づいてアクセスログとして扱われる場合があります。

5. 第三者サービス

AMAGUMOは地図描画にMapLibre Nativeを使用します。データ提供元と利用条件は次のとおりです。

  • 気象庁 雨雲の動き
  • 気象庁ホームページについて
  • 地理院地図Vector
  • 地理院地図 利用規約
  • MapLibre Native

6. App Store

Appleは、App Storeの利用や診断に関する集計情報をAppleのプライバシー方針に従って扱う場合があります。AMAGUMOは独自の解析SDKを追加しません。

7. 問い合わせ

問い合わせ先はサポートページをご確認ください。

8. 改定

本ポリシーは、アプリ機能、通信先、利用するデータの変更に応じて更新します。
