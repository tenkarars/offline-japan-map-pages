iPhone app

RAIN PREVIEW

開いてすぐ、現在地の雨量変化を色で確認。

起動時は雨量色、その後は雨雲地図

RAIN PREVIEWは、気象庁の「雨雲の動き / 高解像度降水ナウキャスト」を国土地理院のベクトル地図に重ねて表示する、オンライン専用のiPhoneアプリです。端末上では「RAIN PREVIEW」と表示されます。

通常の起動時、条件が整うと、現在地セルの最新実況解析を「0」、同じ解析時刻を基準にした最大60分先までの予測を「+5」などの相対時間（分）として、気象庁の雨量強度色で一度だけ順に表示します。欠損した時刻や色は生成・補間しません。

全画面の色の背景には、地理院地図と最新実況解析に固定された雨域が見える場合があります。予測雨域を地図上で自動再生する機能ではありません。終了後は通常の地図へ戻り、観測・予測時刻を手動で切り替えられます。

条件が整わない場合は起動時表示を省略します。無料で、広告、アカウント、外部解析SDKはありません。

App Storeで公開準備中です。

安全に関する注意

RAIN PREVIEWは気象庁や国土地理院の公式アプリではありません。雨雲の表示は、避難、通行、登山可否などの安全を判定するものではありません。公式情報と現地状況をあわせて確認してください。

兄弟アプリ
