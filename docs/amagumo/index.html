iPhone app

AMAGUMO

開いてすぐ、現在地付近の雨雲を確認。

観測と予測を地図で確認

AMAGUMOは、気象庁の「雨雲の動き / 高解像度降水ナウキャスト」を国土地理院のベクトル地図に重ねて表示する、オンライン専用のiPhoneアプリです。

観測時刻と予測時刻を切り替え、雨雲が近づく時間や弱まる見込みを確認できます。無料で、広告、アカウント、外部解析SDKはありません。

App Storeで見る

安全に関する注意

AMAGUMOは気象庁や国土地理院の公式アプリではありません。雨雲の表示は、避難、通行、登山可否などの安全を判定するものではありません。公式情報と現地状況をあわせて確認してください。

兄弟アプリ

圏外で使う地図保存、GPS現在地、予定ルート、チェックポイントには「オフライン登山地図」を利用できます。両アプリはそれぞれ単独で利用できます。
