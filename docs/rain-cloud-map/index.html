気象庁の雨雲データを使用

気象庁の「雨雲の動き / 高解像度降水ナウキャスト」を地図に重ねます。選択中の時刻が観測データか予測データかを表示し、最大60分先までの予測を確認できます。

地図、ルート、現在地と重ねて確認

雨雲の透明度を調整しながら、登山道、予定ルート、チェックポイント、GPS現在地を同じ画面で確認できます。

雨雲表示はオンライン専用

雨雲データは保存した地図に含まれず、表示には通信が必要です。実際の天候と異なる場合があり、登山可否や安全を判定する機能ではありません。現地状況と公式情報をあわせて確認してください。

雨雲と予定ルートを同じ地図で

雨雲の動きは、ユーザーが表示操作をした時だけ取得します。
