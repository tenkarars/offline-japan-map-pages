登山前に必要な範囲だけ保存

国土地理院の地図から範囲を選び、地図データを端末へ保存します。保存する前に範囲とデータ量を確認でき、複数の地図を名前やグループで整理できます。

圏外で確認できるもの

  • 保存した地図
  • iPhoneのGPSで取得した現在地
  • 予定ルートと日本百名山の同梱ルート
  • 自分で追加したチェックポイント

GPS現在地の取得には携帯回線は不要ですが、端末や周囲の地形によって測位精度や取得時間が変わります。

オンラインが必要な機能

未保存地域の地図取得と「雨雲の動き」はオンライン専用です。出発前に機内モードなどで保存した範囲が表示できることを確認してください。
