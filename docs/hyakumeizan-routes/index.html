山カードからルートを表示

山名を検索し、山カードにある登り・下りのルートを選ぶと地図上に表示されます。ルート周辺の地図を保存し、圏外で確認する準備もできます。

地形図と登山道を同時に確認

予定ルート、登山道強調、チェックポイントを同じ地図上に重ねられます。分岐や地形を確認し、自分の計画と照合するための参照情報として使います。

現地の公式情報とあわせて確認

同梱ルートは登山の安全や通行可能性を保証しません。登山道の閉鎖、火山情報、天候、季節による状況は変化します。出発前に自治体、山小屋、交通機関などの最新情報を確認してください。
